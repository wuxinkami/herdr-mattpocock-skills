# 使用 agent 环境中的 Matt skills

Matt 技能正文、资源和版本以 agent 环境中的原安装为准。本包只维护 Herdr 的职责、工具、会话边界与交接规则。

## 定位外部技能

1. 从当前执行端提供的技能清单定位用户选择的工作流，沿用其调用策略，使用清单中实际的名称、namespace 和读取方式。文件型技能读取对应 `SKILL.md`；宿主资源通过其原生接口读取。别名只采用清单或技能正文已声明的映射，`implement` 与 `implement-spec` 保持各自含义。
2. 清单未提供入口时，核对该宿主实际配置的项目级、用户级、共享或 plugin 技能位置。例如项目 `.agents/skills`、`.claude/skills` 可能提供入口，但以当前环境的有效配置为准。同名候选沿用宿主已解析的有效项或用户指定来源；无法确定时先澄清来源。
3. 读取选定技能当前所需的正文与资源。相对链接始终相对该外部技能原目录解析，后续调用的其他 Matt 技能也按此方法定位。使用当轮已解析的来源，不在本包内生成正文副本或解压源码作为备用入口。
4. 仅要求当前步骤用到的技能。缺失、路径不可读或宿主无法加载时，列出技能名称、已检查的入口和具体缺口，暂停依赖它的步骤；不能用空结果报成功、静默换同名版本或替换成另一条工作流。

派工时传递实际技能名称、已解析的绝对路径或宿主资源标识、已知版本及本次执行阶段。版本未知时如实说明。接收端先验证能读取同一来源及所需资源；跨工具或机器不可达时回报调用方处理，不自行换成另一份本地版本。本包的安装、更新和卸载只管理 Herdr 适配文件，外部 Matt 安装由用户原有方式维护。

## 把原流程映射到 Herdr

执行外部技能的业务步骤、依赖、TDD、审查视角和完成条件；涉及执行者、工具和上下文的步骤按 [职责](roles.md) 与 [路由](routing.md) 落到本轮已确认的配置。遇到新调用点，按实际工作确定职责和载体；需要未确认配置时交秘书处理。

- **原地引用**：grilling、领域词汇、TDD 和写作参考等由当前职责按需读取。读取一个技能本身不创建新会话，也不重新启动秘书。
- **独立执行**：原流程要求 fresh context、subagent、后台任务、独立 proposal 或跨工具交接时，使用对应职责的已确认执行端。显式职责用 Herdr；匿名职责用配置的后台 CLI，允许 `native` 的职责仍须验证工具、模型和思考等级匹配。
- **执行叶**：派工明确到任务、阶段或审查轴线。Searcher 收到 research 任务后直接研究；reviewer 只审自己的轴线。原技能中的顶层 launcher 由调用方协调，不让执行叶递归再启动同一套团队。
- **检查与 Git**：Worker 保留功能自测和正常测试内部编译；独立 build、lint、typecheck 或委托脚本交 checker。Git 操作按本项目用户授权及秘书、PM、merger 的职责执行；角色分配和原技能的默认步骤都不扩大授权。

外部技能对 tracker、权限、产品专用 CLI 或手动步骤的要求仍然适用；只适配实际的 agent 派工与协作调用。若所需会话边界与当前模式或载体冲突，指出冲突并由秘书处理。

## 关键工作流的衔接

- **wayfinder**：秘书维护 map 和依赖，为就绪、未认领的决策票开新的 griller 面板；AFK research 交 searcher。子会话写回规范结果后按 [回报协议](routing.md#子会话主动回报) 通知秘书，秘书回读证据、核验状态、关闭已完成面板，再推进下一就绪票。用户在 griller 面板回答，秘书不代答；原流程的人类决策和完成条件保留。
- **设计 → 实现**：按已安装工作流形成所需材料。只有已确认目标包含实现时，才进入 [秘书开工确认](../SKILL.md#秘书发起开工确认)，确认并归档后交 PM；只要求规划或非工程产物时按原 destination 交付。
- **implement / implement-spec**：PM 执行用户选定且环境实际提供的入口，沿用该版本的任务图、TDD 和 review 节点。新实现任务和独立返修任务使用新的相应 worker；需要基于 HEAD 的审查时，由 PM 在授权范围内准备真实可审查的提交状态。
- **code-review**：原流程要求的 Standards / Spec 等视角分别使用 fresh 匿名 reviewer，保持并发和汇总语义。调用者提供相同的固定代码状态、spec、standards 与原技能要求的完整 brief；叶 reviewer 不再执行整个 review launcher。

同一轮工作只使用已解析的外部来源。Matt 更新后的新增派工、资源或会话要求按实际正文重新核对；本包不锁定一份 Matt 快照，也不维护独立的 Matt 流程目录。
