# CLI 模型与思考等级

核对日期为 2026-11-18。命令列出单次启动的参数。模型 ID 和可用档位由所选提供商、账号和 CLI 版本决定。

| CLI | 模型 | 思考等级（交互／无头、条件） | 一手来源 |

只在项目选到相应工具时补充映射。给 Cursor 或 Vibe 填变体时，右侧须是账号或预设中确实对应该等级的完整 ID。例 `{"tools":{"cursor":{"modelVariants":{"项目型号":{"high":"实际变体ID"}}}}}`。Vibe 的这项映射位于 `tools.mistral-vibe.options.interactive.modelVariants`。

旧 Hermes 可在 `tools.hermes` 填 `"interactive":["hermes","{profile}","chat","{model}"]`、`"headless":["hermes","{profile}","chat","{model}","--quiet","--query","{prompt}"]`、`"effortProfiles":{"high":"已有profile"}`。该 profile 应为所选型号实际设置 `agent.reasoning_effort` 或 `agent.reasoning_overrides`。
